# Germanium Detector Communication Protocol

This repository contains the protocol definition used by Germanium detector software, between `ZynqDetector` running on the detector and `ADGermanium` running on the IOC server.

## Usage

Refer to `GermaniumDetectorProtocol.hpp` in `ZynqDetector` and `ADGermanium` for message structure and constant definitions.

## Revisions

- v1.0: register definitions from FPGA firmware v18 and newer.
